## [0.1.0] - 2025-01-18

Initial release.

### Added

- `Quantity`, `Unit`, and `Dimension` core types with runtime dimensional analysis
- Exact rational exponents via `Rational16`
- SI, CGS, astrophysical, imperial, and logarithmic unit systems
- 12 equivalencies (spectral, Doppler, parallax, mass-energy, temperature, brightness temperature, and more)
- Unit and quantity parsing with Unicode, LaTeX, and natural language support
- Batch conversion API for high-throughput workloads
- CODATA 2018 physical constants
